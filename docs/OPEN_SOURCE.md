The rows marked *(optional)* are used only by the optional ML triage benchmark (`requirements-ml.txt`). They are imported lazily, are not in `requirements.txt`, and every other part of the software works without them. On LinuxONE (s390x) they come from the LinuxONE ML container image, not from PyPI. The versions listed are those the benchmark was tested with on macOS arm64; the same results were reproduced with scikit-learn 1.5.1 / NumPy 1.26.4. The LinuxONE ML image also ships XGBoost, pandas, TensorFlow and PyTorch; this project does not use them.

Development tooling (not part of the delivered software): Jupyter / nbconvert were used to test the LinuxONE notebook.
